## Reflection
To create the best team, and development in a project, documentation is very important. 

Version control is creating a possibility for a shared history and makes it easier to collaborate. Automated tests help catch regressions when code changes and makes it clear what is expected behavior from the code. Team members can easily share knowledge solving problems and errors together with pair/mob programming, and peer reviews give us different perspectives and can improve the quality of the code. All of these practices makes it so each team member has ownership over the project, and can share the responsibility of the project itself.
